## 3. 射程＝不變式（不是機制）

*   **M1 讀回的欄位是一個值**（r1）：十一形，各以兩種方式讓效應第一次在提交時做——讀者先提交、`g` 後寫；`g` 先純、再 pin 成 append——兩次 `oo status` 不寫任何位元組，提交寫的位元組數等於寫下的效應數（一形 1；兩個寫法相同的欄位那一形 2）。讀者經：記錄的兩個欄位、清單的三個元素、別名、讀者的讀者、函式本體、記錄欄位的路徑、巢狀路徑、呼叫鏈、呼叫造的記錄。
