## 0. 判準

*   **兩筆寫法相同的記錄是兩個，讀其中一筆的讀者讀的就是那一筆**：一次寫下 `q: { r1: { a: g "x" }, r2: { a: g "x" } }`、`k: q.r1.a`，提交時效應做 2 次（`r1.a`、`r2.a` 各一次）。三層、別名再讀、清單或元組裡、根上兩筆、經函式、呼叫造的、讀者在記錄或清單裡、經函式回傳的 union、讀者寫在第二次演化，都一樣。
*   **一個值，兩個就是兩個**：`a` 是 `~%Math./random ()` 時，`k = q.r1.a` 是 `#true`，`k = q.r2.a` 是 `#false`。
*   **讀惰性效應欄位的定義存它自己的語法**：`k: q.r1.a` 存 `k: q.r1.a`，不存 `#true`（與 `k: a`、`k: l.0` 已經存語法的一致）。

*   演化求 `q.r1.a` 時，路徑走到 `r1` 那一欄就回傳那一欄的惰性 thunk（`g "x"`，閉包是 `q` 與 `r1` 的框），沒有強制、沒有碰到效應——D129 那一支（`LAZY_HIT`、`EFFECTS_SKIPPED`）沒有觸發，`k` 的值就成了 `r1.a` 那一欄本身。
