## 0. 判準

*   **D127（用戶裁定，乙；存法同日第二問「快照留著，寫入並存」）**：一筆寫入遇上宇宙存著的視界——坐標本身是視界，或讀起來某處是視界——**兩個都記下**；一個視界寫在存著的值上，同樣兩個都記下。視界照舊是它的快照（身分、`%caid` 不動）；讀那個坐標答那個快照。什麼都不丟，也不替讀的人判一個讀的人判不出來的東西。
*   **判撞不撞，看的是讀的人讀得到的**（D113「交會途中被強制的定義照常計費」）：宇宙的檢查在免費的交會裡強制一個定義時，那個定義仍是一次觀測、一份燃料。讀的人讀到視界，檢查就不得因為自己多算了而拒絕。
*   **判得出來的照判**：讀的人讀得到值（`r: /f 50` 讀 `0`），寫入照舊與它比、衝突照舊具名拒絕。
*   直接求值的 `/f 5000 & 7` 照舊答視界（`SPEC_08` §3.2.2、`SPEC_01` 診斷成員豁免）；本卡只動宇宙怎麼記。

## 1. 缺陷

〔量，`v0.121.0` 標籤建置；`acc/q121/recon.py`、`shapes.py`、`kept.py`〕

*   **寫在視界上的值不見**：`/f: (x -> x == 0 ? 0 : /f (x - 1))`、`r: /f 5000` 提交後寫 `r: 7`：演化收下、提交答 `already in HEAD`、根裡只有 `r: #blur …`。兩次演化後一次提交、同一個檔寫兩次，同。一個閉合的、燃料用完的定義（`r: (3000 欄 & 3000 欄).k2999`）、呼叫的答案、`H + 1`、清單元素，同。
*   **寫在值上的視界把值抹掉**：`r: 7` 提交後寫 `r: /f 5000`：提交成功，根裡只有 `r: #blur …`，`7` 不見；兩次演化、同一個檔，同。
*   **判撞不撞時白算了一個定義**：`h: { a: (3000 欄 & 3000 欄).k2999 }`（從根上讀 `_.h.a` 是燃料視界）之後寫 `h: { a: 7 }`：**被拒** `#conflict at h.a`；反方向（先 `h: { a: 7 }`）同。10 欄時讀 `9`、拒絕是對的。檢查在 `meet_clash` 的免費交會裡直接 `force` 那個欄位的定義，`FREE_MEET` 沒有被清掉，定義裡使用者寫的 `&` 也不花燃料——讀的人算不出來的，檢查算出來了。**這是 Q-120 的 m12（「免費交會裡的定義內部也免費」）——Q-120 驗收時寫「量過的格逐格同」，那個說法是錯的：v0.121.0 上這一格就走得到。**
*   **對照**：`r: /f 50` 之後寫 `r: 7` 具名拒絕、寫 `r: 0` 收下；`r: 7` 之後寫 `r: /f 50` 具名拒絕。記錄裡讀宇宙的欄位（`h: { a: /f 5000 }`）本來就存成兩筆寫入的語法，`7` 還在。
