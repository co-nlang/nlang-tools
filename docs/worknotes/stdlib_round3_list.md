B3 — ~%Query（Combo 路徑查詢）

類 JSONPath，對嵌套 Combo 進行結構查詢，無需新 dep：
```
┌───────────────────┬───────────────────────────────┐
│       態射        │             說明              │
├───────────────────┼───────────────────────────────┤
│ select(path)      │ "field.subfield.2" → 深層取值 │
├───────────────────┼───────────────────────────────┤
│ where(pred_combo) │ 對 @list 中的 Combo 過濾      │
├───────────────────┼───────────────────────────────┤
│ pluck(key_list)   │ 取多個欄位組成新 Combo        │
├───────────────────┼───────────────────────────────┤
│ deep_merge(a, b)  │ 遞歸合併兩個 Combo            │
└───────────────────┴───────────────────────────────┘
```
