## 3. 必答題

**Q1 — 值遺失的窗口，構造一個判別實驗。** 第 2 輪的 19/20 是觀測到的，

說出哪兩個時點交錯會丟一個座標，並附一次可重現的紀錄。

**Q2 — `os error 2` 是哪一個檔、哪一個呼叫？** 逐字給出路徑與呼叫點。
**並回答它是不是 Q-016a／Q-040 造成的**——那兩弧把 `let _ = load_staged` 改成 `?`，
使先前被吞掉的錯誤現在會浮出來。**若是，說清楚：那不是回歸，是原本就在的東西第一次被看見。**

**Q3 — `Nothing to commit` 在什麼條件下印出來？** 它今天是不是唯一的「工作集為空」出口？
若是，**要分辨「本來就沒有東西」與「有東西但被別人消費了」需要什麼**（不要實作，只要價）。

**Q4 — 假設 tip 唯一的地方在哪裡？⚠ 不要給我一份清單，給我一個不變式。**
〔驗收方已知的起點，**不完整，不得當成清單用**〕`savepoint.rs::record_commit`
的 `ancestor: Option<&str>` 是**單數**，covering parent 也被硬取一個
（`vec![p]` 或 `tips.into_iter().next()`）。
**問句是：如果有兩個 tip，哪些讀者今天會給出錯誤答案，而判準是什麼？**
（`oo log`／`squash` 的祖先走訪／`gc::mark`／`rollback` 都要查，
但**我要的是「凡……者」那句話**，不是那四個名字。）

**Q5 — 三個候選各自的價，用同一把尺。** 對甲／乙／丙各報：
(a) 動到哪些檔、量級；(b) **是否動磁碟表示**（若動，就是又一次 `layout` 與破壞性條目——

**Q6 — 丙有沒有隱藏成本？** 具體地說：拒絕之後操作者要重跑，
**而他的工作集還在嗎**？（今天 commit 會清注入目錄；若晚到者被拒但注入已被贏家清掉，
那個「重跑」是重跑不了的。）**這一題可能決定丙是不是真的便宜。**
