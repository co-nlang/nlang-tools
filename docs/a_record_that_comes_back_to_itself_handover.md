## 0. 判準

*   **宇宙為自己的簿記強制一個值時，每一格各自一份預算**（`SPEC_10` §2.3.1，Q-120）：一格存什麼、報什麼、收下或拒絕什麼，不隨同一筆寫入裡有多少別的格而變。
*   **一格是寫下的那一格**：一筆記錄有兩條路回到自己（欄位讀兄弟、閉包的框、清單），回到的是同一筆記錄、同樣的格，不是 2^深度 個新格。同一趟走訪回到一個正在走的格，那一格的內容已經在判。
*   **存下的根、讀數、拒絕不變**：沒有第二條路回到自己的值（含一條路的環、讀兩次的記錄、呼叫造的記錄、遞迴）與 v0.134.0 相同；遞迴每一層是同一個式子、不同的框——不是回頭路，三層下的 ⊥ 照樣找得到。

## 1. 缺陷

〔量，`acc/q135/recon.py`、`branch.py`、`bisect.sh`、`dbg/count.py`；v0.119.0 到 v0.134.0 標籤建置，v0.120.0–v0.123.0 重建；每程 3 GB〕

*   最小的形：`a: { e: x, x: a }`。一條路的環（`a: { x: b }`、`b: { y: a }`）正常；兩條路的——讀兄弟、閉包的框（`e: (n -> x)`）、清單（`x: [b]`、`b: [a]`）——演化或提交不返回、或 3 GB 用完中止。
*   **工作量是 2 的（深度上限／環長）次方**：環長 L+1、頭一格讀兄弟，`oo eval` 秒數 L=63／41／31／25／21／18 為 0.8／2.0／3.4／7.4／17.2／48.5，L=16 逾 60。
*   **燃料擋不住**：L=25 的 `force_recursive` 20 萬次裡 19 萬次在每格一份預算下，每往下一格燃料重設；總花費 39.7 萬（預設 1 萬）。
*   **回歸**：v0.119.0、v0.120.0 正常（一份燃料）；v0.121.0（Q-120 落地）起提交與 `oo eval` 不返回；v0.123.0（Q-122 演化也做 ⊥ 檢查）起演化也不返回。
*   `oo eval` 也走這裡：它先把表達式演化進暫存（`evolve_field` → `bookkeeping` → `force_each_cell`）。

## 6. 明文不在射程內

*   **讀這種值要 GB**：`oo eval '{ a: { e: x, x: a } }.a'`、讀已提交的 `_.a` 整個印出——一次觀測（一份燃料）裡值沒有共享，每一層深複製；v0.120.0 讀 `_.a` 也要 2.5 GB。Inbox「值沒有結構共享」。讀小的投影（`_.a.v`、`_.a.e.x.v`）不受影響。
*   **值本身就是 2^N 大**（`id: (x -> [x, x])`）：Inbox 既有列。
*   **環長的平方**：每個坐標各自一份預算、各走一圈環，129 筆的環演化約 3.5 秒——Q-120 的取捨，不是加倍。
