## 1. 一句主張

〔量，`v0.52.0` 標籤建置，對照組 `"x"` ≠ `"y"` 活著〕

```
"ab"  r"ab"  p"ab"  u"ab"  t"ab"     五個值，一個位址 2f5992b8…
"()"  ()                             兩個值，一個位址 5f6b36a7…
"6162"  b"ab"                        兩個值，一個位址 4414b39b…
```

每一對 `=` 皆 `#false`，而 meet 全部吸收（`("()" & ())` → `"()"`）。
成因：`serialize_atom` 有八條臂都推 `TAG_ATOM`（`0x10`）再寫一個裸字串
（`Str`／`MultilineStr`／`Code`／`PathLit`／`Unit`／`Regex`／`Uri`／`Time`／`Bytes`）。

## 2. 射程 ＝ 兩條不變式

**I1　語言分得開的兩個值不得共用位址。**
判準是 `=`／反射 `%id`，不是「哪一條臂」。凡今天 `=` 判 `#false` 而位址相同者，本弧治它。

**I2　一個值的種類必須進入它的位址。**
身分不得只由「它的文字碰巧長什麼樣」決定。
**這一條比 I1 強，而它是刻意的**：只滿足 I1 的修法（例如給四個前綴字面一個共同的新標記）
會讓探針 R2 的第一個迴圈通過而第二個迴圈紅——**兩個迴圈都要綠**。

## 3. 必須做的事

**S1　讓每一種 `AtomKind` 的位址分得開。** 標記位元組怎麼配是交付方的決定，
但**必須是決定，不是巧合**：交付回報要逐項列出最終的標記配置（見 S3）。

**S2　不得動 `=`、不得動任何求值語義。** 本弧只治身分。

**S3　交付回報必須附一張逐位元組的標記表**：每一個今天會被寫進 CAS 的標記位元組、
它的意思、以及它的酬載形狀。**這張表是規格結案的輸入**（`REAL_03` §6.2 由驗收方寫）。
表裡必須包含今天 §6.2 缺的五個：`0x17` Thunk／`0x18` Range／`0xFD` Blur／`0xFE` Bottom／`0xFF` Top
——後三個今天**連具名常數都沒有**，是逐字 `buf.push(0xFD)`。

**S4　紀元範圍要量出來寫，不得只說「應該很少」。**
至少三處分母：conformance 語料、引擎測試 `.n`、`examples/`，
各有多少 `r"`／`p"`／`u"`／`t"`／`b"`／`()` 值，以及標準根裡有沒有。

## 6. 工單指名要你回答的問題（N.4 逐題作答，答案不利也照寫）

**Q1　`serialize_union` 不推標記也不推長度前綴，這會不會造成碰撞？**
**驗收方只讀了碼，沒有量到**，而且**曾經量錯過一次並已作廢**：
`~%Discovery./identify_and_store` **對 union 逐元素分配**，回的是一個 CAID 的 union，
驗收方的 helper 只取了第一個，於是讀出三筆假的「union 與首元素同址」。
⟹ **請用一個不會對 union 分配的入口真的量一次**，並寫出你用的是哪一個入口、
以及對照組是什麼。**若量不出碰撞，就寫「量不出來，方法是 X」**——那也是答案。

**Q2　`AtomKind::TagStart`／`TagEnd` 被編成名字為 `"_"`／`"_|_"` 的 tag。
它們與真的 `#_`／`#_|_` 撞不撞？** 若表層寫不出那兩個 tag，寫「寫不出來」並附證據。

**Q3　`Thunk`（`0x17`）與 `Blur`（`0xFD`）今天從表層語法碰得到嗎？**
碰得到的話，它們的位址有沒有同族問題？碰不到就說碰不到，並說你怎麼確認的。

**Q4　你配的新標記位元組，有沒有與既有的任何一個相撞、或落在未來會用到的區段？**
說明你怎麼選的。

### N.4 工單指名要你回答的問題

**Q1** 量不出碰撞。入口：`~%Discovery./identify_and_store { u: (1 \| 2) }`（引數是 Combo，不會對 union 分配）。對照：裸 `(1 \| 2)` 經同一入口回兩個 CAID 的 union（`a8b1b4fe… \| 17564af7…`，即 2 與 1）——這是驗收方作廢的那條路。包著的 Combo：`{ u: (1\|2) }` `60a0a450…` ≠ `{ u: 1 }` `4141b60a…` ≠ `{ u: 2 }` `94fa9807…`；`{ u: ("a"\|"b") }` `08c33a67…` ≠ `{ u: "a" }` `bc8938f4…`。`%id`（v1）對 union 有 `0x03` 前綴，`(1\|2).%id` `abdb8eee…` ≠ `1.%id`。成員編碼皆自定界，串接不是單一原子的編碼。單元素 Union 在 `normalize_union` 塌掉，不會以「無標記的一份拷貝」入雜湊。

**Q2** 表層 `#_`／`#_|_` **就是** `TagEnd`／`TagStart`（pest：`tag_start = { "#_|_" }` 先於 `tag`）。`#"_"` 是 parse error。寫不出 `AtomKind::Tag("_")`／`Tag("_|_")`。它們的編碼（`0x11`＋`"_"`／`"_|_"`）若能寫出那兩個 Tag 會撞；寫不出。`(_ = #_)` `#false`（Top 對 TagEnd）。未改這兩臂。

**Q3** **Thunk**：pest 無 thunk 字面。`$` 回 ⊥ `#no_context`，不是 `Value::Thunk`。`#open`／`#thunk` 是 Tag。**Blur**：pest 無 blur 字面。`#blur` 是 Tag。`~%Engine./blur` → `#missing_key`。燃料耗盡是執行期，不是表層。**Range**（旁註）：`1...3` parse error；`1..3` 碰得到，自有 `0x18`。

**Q4** 新標記 `0x19`–`0x1F`，接在已占用的 `0x18` Range 後面。未重用 `0x03`／`0x04`／`0x15`（保留、今天不發出）、未用 `0x00`、未進 `0xF0`–`0xFC`（靠 `0xFD`–`0xFF`）。`0x10` 留給 Str，故 `"a"`／`0`／`1.5`／`#true` 不動（G4）。
