# 一個付了整個工作集的視界（Q-130）

探針：`crates/oo/tests/a_horizon_that_paid_for_the_working_set_probe_test.rs`（不得修改）。
佇列：`nlang-spec/meta/WORK_QUEUE.md` §3「2026-11-17 — 開 Q-130」。

## 0. 判準

*   **一筆寫入的成本由寫入的大小界定**（Q-116、Q-117、Q-128 同一個不變式）：N 個坐標的寫入，4N 個的時間少於 N 個的 8 倍。
*   **視界是快照**（D127）：存下的視界不因之後到的坐標而改讀數。
*   **不須裁**。

## 1. 缺陷

〔量，`v0.128.0` 標籤建置；`acc/q130/blur.sh`、`chain.sh`〕

*   **每一個落地成視界的坐標，付一次整個工作集**：`/f: (x -> x == 0 ? 0 : /f (x - 1))`、`h: /f 5000`，再加 N 個 `k_i: h + i`，同一次 `evolve`：N=500／1000／2000 演化 9.53／34.60／142.02 秒（平方級）。同樣的欄位讀 `h: /f 50`（存配方，不是視界）：5.99／11.36／22.35 秒。
*   **超過深度上限的鏈，名字先寫**：每一節都存成視界（D130），N=400／800 演化 5.08／21.36 秒；讀者先寫 4.83／11.70。
*   **成因**〔讀碼，修法驗證〕：Q-117 的就地落地只收原子、配方、由它們組成的記錄與聯集（`fast_value`），視界不在裡面，所以每一個視界都走完整交會加整份重新蓋章。
*   **為什麼現在要修**：Q-127 的參考照讀取順序落地，每一種寫法都付名字先寫的價——純鏈 N=2000 約 125 秒（v0.128.0 讀者先寫 32.57、名字先寫 136.48）。

## 2. 依據；位址

*   **不須裁**（§0）。
*   **位址不動**：本卡只改成本。g1 十一格（讀視界、就是視界、local、超過深度的鏈名字先寫、燃料的視界、兩次 `evolve`、清單與元組與聯集、疊在 HEAD 上的三種）的根與讀數都釘 v0.128.0。視界之後存什麼與順序有關（D130），g1 照 v0.128.0 各自存的那一顆釘，不要求兩序同根。

## 3. 射程＝不變式（不是機制）

*   **M1 撞上視界的寫入照寫入的大小計價**（r1）：五形，N=500 對 2000，2000 的少於 500 的 8 倍——每格讀一個視界（`k_i: h + i`）、每格就是那個視界（`k_i: h`）、local 坐標讀它（`~k_i: h + i`）、超過深度的鏈名字先寫、視界在一次 `evolve` 而讀者在下一次。
*   **M2 每一次就地落地都是交會的**（r2）：十二形加三個疊在 HEAD 上的，開 `OO_Q117_SHADOW`，不 panic 而且確實比了。其中三形是**不是視界、交會又不會原樣留下的值**放在視界旁邊：聯集裡含 ⊥、`_`、引用——放寬過頭的做法在這裡會不同。
*   **另一半**（g1）：根與讀數照 v0.128.0（§2）。
*   **上一張卡學到的，逐條過**：
    *   **每一種視界**：深度（`#max_depth_exceeded`）與燃料（`#fuel_exhausted`）都在 r2、g1 裡；燃料的視界每格各付自己的燃料，不放進 r1。
    *   **疊在 HEAD 上**（D127：兩筆都留）：HEAD 有值再寫視界、HEAD 有視界再寫值、讀 HEAD 上的視界——r2 與 g1 各三格。
    *   **規模到幾千**：r1 的 2000；Q-128 r1 的 8000 照舊在全樹裡。
    *   **捷徑與原路**：`OO_Q117_SHADOW`（Q-117、Q-128、Q-129）。

## 5. 必答（請在交付報告裡回答，逐題）

*   **Q1 為什麼一個視界可以不經交會就放進去**：寫出前提（坐標上原本沒有東西、視界的讀數不因之後的坐標而變），並說明每個前提在你的做法裡由哪一個判斷守住。
*   **Q2 你收了哪些值**：`Value` 每個變體逐一說收不收、為什麼；收的是頂層的視界，還是也收裝在記錄、聯集裡的。
*   **Q3 疊在 HEAD 上**：HEAD 在那個坐標上有值、有視界時，你的做法與完整交會各存什麼（D127）。
*   **Q4 成本**：r1 五形、Q-128 `cost.sh` 八形 2000／8000、§1 的兩組（`k_i: h + i` 與超過深度的鏈兩序）500／1000／2000，對照 v0.128.0。

## 6. 明文不在射程內

*   **每個讀者各走一次它讀的配方**（既有 Inbox「配方鏈每個讀者重走一遍」的另一半）：N 個讀者讀同一個配方，演化是 N 乘以配方的長度；長度被深度上限截住，是線性的。讀者先寫的長鏈 N=800 11.70 秒是這一項。
*   **撞上視界之後存什麼與順序有關**（D130，已裁）。
*   **清單裝著一筆裡面有效應的記錄，提交時效應做兩次**（Q-127 偵察旁量，新開 Inbox）。
