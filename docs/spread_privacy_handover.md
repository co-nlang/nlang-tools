## 0. 法(既有,無新裁定)

SPEC_03 §3.1 私有保全條款:「若展開操作位於目標 Combo **外部**,則
目標中的 `~` 私有欄位將**不會**被包含在展開結果中。這防止了透過
`...` 運算子非法導出內部私有狀態。」

量測(v0.2.11):spread 無條件搬運六軸;外部 `q: { ...p, peek: ~s }`
取得 local 軸副本,私有軸弧的 seal 使副本可讀(peek → 1)——外洩
原語。(v0.2.10 副本已搬但讀不到;非私有軸弧回歸,是既有搬運+
新可讀性的交互。)

**內外判準**:沿 SPEC_04 §3.1 #5 幾何路線——展開**目標 combo**
出現於當前求值語境的 scope 鏈(ctx.scopes + Thunk 閉包 frame,結構
等值)= 內部;否則外部 → 複製 data/rules/types/meta/system 五軸,
**local 軸不搬**。

## 1. 地圖與實作建議

1. spread 求值點(eval.rs `...` 展開臂):取得目標 combo 後、逐欄
   搬運前,做內外判定;外部 → 跳過 local 軸欄位。
2. 內部判定:目標與 scope 鏈 frame 逐一結構比對(frame 數小,
   PartialEq 成本可接受);**用整 combo 等值**,勿用欄名啟發式。
3. 注意判定時機:在 seal_defining_scope **之前**的原始展開處
   (spread 是字面量建構的一部分)——當前 ctx 的 scope 鏈即判定
   依據,不需要额外機構。

## 2. 邊界與陷阱

1. **內部展開保全**:條款是條件式——內部 spread **保留** local
   (釘 `pin_insider_nested_spread_keeps_local`:`p.c2` 內 `...p`
   後 `rd: ~s` → 1 今日即綠,修後須仍綠)。
2. **展開私有目標的公有欄**照常(`{...~c}` 之 x 是 ~c 的公有欄;
   釘×2:語料形+SPEC_03 自例)。
3. **`&` 合併勿動**:六軸 unify 是值層法(A&B≡A 幾何);字面量
   另行 seal 已擋讀取(釘凍結)。
4. **展開碰撞交集合併勿順手修**(`{a:1, ...{a:2}}` → 覆寫 vs 法定
   `1&2`——已記帳另案;本單勿改碰撞行為,避免變因混合)。
5. **List/Range 展開**不涉 local 軸,不動。
6. **效果釋放語義**(SPEC_03:spread 釋放內部效果標籤)不動。
7. 私有軸弧回歸守衛:外阻/顯示剝除兩釘在檔。
8. 全語料回歸 + conformance L2-36/37(今日紅)、L2-38(今日綠)。
9. 交付紀錄照舊格式(根因、diff、量測、未動聲明)。
