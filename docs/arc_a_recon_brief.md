## 0. 這一弧是什麼

`oo evolve` 今天是一個動作做兩件事。設計帳已把它拆開並裁完，六則裁定
（`nlang-spec/meta/oo/STATUS.md` D42–D47，全文在 `meta/oo/commit.md` §1.10）：

| | 裁定 |
| :-- | :-- |
| **D42** | **注入**（與宇宙做 `&`，**不求值**）與**觀測**（收斂一條已定路徑）是兩個獨立動作。一次做兩步的複合入口容許存在，**但那是 UX 層，不得是語義層** |
| **D43** | **持久 ≠ 固化**。每個 ○（savepoint）都已經是持久的；● 的前提是**能不能算出 CAID**，不是「可分享」 |
| **D44** | **⊥ 的觀測結果也必須產生 ○**（否則 `%cause` 沒有可指的對象） |
| **D45** | **`固化` 一字退休**（或只留求值義）。正準三字＝**注入／觀測／commit** |
| **D46** | **固化深度不進 ●，除非那一格不可重現**。`#pure` ⟹ ● 保留 thunk；`#io`／`#nondet`／`#state` ⟹ 強制後的值必須進 ● |
| **D47** | **○ 的產生判準**：注入 ⟹ 格上位置變；觀測 ⟹ **有 thunk 被真的化約** |

**先讀 `meta/oo/commit.md` §1.10 全文再開始。** 本文只列要你去量的東西。

## 1. 驗收方已經量過的，不要重量

〔量 2026-08-28，v0.37.0 標籤二進位〕

1. `.oo/` ＝ `format`(`layout=2`) / `objects.format`(`encoding=5`) / `objects/sha256/…` /
   `HEAD`（單行單一 CAID）/ `staged`（單一檔、28 B、框 `#nlang/store staged`）。**無 `refs/`**。
   **`staged` 在 commit 之後被刪除。**
2. **commit 會強制求值每一個 thunk**：staged 逐字 `c: a + b`，提交後根裡逐字 `c: 3`。
3. **算不出來的一格在 commit 變 `_`，定義永久遺失**：`c: a + b`（`a`/`b` 未定義）
   → 根 `c: _`；之後補上 `a: 1` / `b: 2` 再 commit → **`c` 整格消失**，`_.c` → `_`。
4. **拆檔語義差異仍在**：同檔 → `c: 3`；拆兩檔 → `c: a + b`（補上 `a` 後也不回頭）。
5. **兩序注入同根**：`@int`/`3` → `654720559d…`；`@int`/`1|2` → `2cab2cd75e…`。
6. **觀測邊界的燃料是固定進場費**：原子與 200 步加法鏈同門檻（fuel=0 → `#blur`，
   fuel=1 → 成功）；30 欄位 combo 於 fuel=1 亦成功。
7. `~%Config` **combo 形**（`~%Config: { fuel: 0 }`）→ ⊥ `#system_reserved`，
   `--privileged`／`--grant` 皆不能繞過；**路徑形**（`~%Config.fuel: 0`）**有效**。
8. `Commit.parent` 有**五處**讀者（`universe.rs:993/1021/1028/1267/1313`），全為歷史走訪。
