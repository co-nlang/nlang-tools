## 1. 缺陷

〔量，`v0.102.0` 標籤建置，空目錄 `oo eval`；**v0.40.0 起每一版皆然**（基線逐版量）〕

*   **點號路徑把字面自己那一框丟了**：`{ p: 1, s: { t: p }, r: s.t }.r` ⟹ `_`（應 `1`）；`s.u.t`、`q: s` 再 `q.t`、`s.0`（`s: [p]`）、`s.4`（`s: { @{ 4 }: p }`）、`s.t 4`、`s.f 0`（`s: { f: (x -> p) }`）同；型別名 `{ @Pos: 1.., s: { t: 0 & @Pos }, r: s.t }.r` ⟹ `0`（應 ⊥）；函式名 `/g 1` ⟹ `_`。對照：`(s).t`、`{ ...s }.t`、`s |> $.t`、`s 4`、從外面讀 `.s.t` 皆對。
*   **裸名是動態作用域**：`{ p: 1, f: (x -> p), r: { p: 3, z: f 0 }.z }.r` ⟹ `3`；`{ p: 1, s: p, r: { p: 3, z: s }.z }.r` ⟹ `3`（`.s` ⟹ `1`）；`{ p: 1, f: (p -> s), s: p, r: f 9 }.r` ⟹ `9`；寫下處沒有、呼叫端有的名字：`{ s: q, r: { q: 3, z: s }.z }.r` ⟹ `3`（應 `_`）。
*   **從外面讀，內層同名沒有蓋過外層**：`{ p: 1, s: { p: 2, q: p, t: q } }.s.t` ⟹ `1`（應 `2`）。
*   **箭頭本體裡的模式解不到外層名字**：`{ @Pos: 1.., /f: a -> { @{ @Pos }: "y", _: "n" }, r: /f 1 0 }.r` ⟹ `"y"`（應 `"n"`）；`(x @Pos -> "y")` 同；兄弟欄位的表經箭頭回傳 `{ @Pos: 1.., g: { @{ @Pos }: … }, f: (a -> g), r: (f 1) 0 }.r` 同；`QUICK_REFERENCE` §7 的 `/safe_div 6 0` 寫在字面裡走到除以零。
*   **寫在檔案頂層的同形全對**（找不到的名字最後回 `ctx.root`）。**提交進歷史的是錯答案**：`n: { p: 1, s: { t: p }, r: s.t }` 提交後 `_.n` ⟹ `{ p: 1 r: _ s: { t: 1 } }`。
*   〔讀＋插桩〕thunk 的閉包不帶它所在字面那一框（`seal_defining_scope` 的框是注入前的快照，快照裡的 thunk 沒有自己的框）；那一框只在**以裸名強制**時補——`force_lexical_name` 設 `lexical_forcing`，`force` 便把**呼叫端整條鏈**接在閉包前 ⟹ 動態。多段路徑在 `resolve_path_internal` 找到第一段後走 `force_coord`，`lexical_forcing` 為空 ⟹ 只用閉包、字面那一框整個沒了（插桩：解 `p` 時鏈上只剩 `[t]`）。箭頭只捕捉本體自由出現的名字（`free_bare_names` ＋ `close_free_dependencies`），而模式鍵 `@{ … }` 與參數模式（`x @Pos`）裡的名字不算 ⟹ 捕捉到的框裡沒有 `@Pos`（插桩 `[[g], [a]]`）。
