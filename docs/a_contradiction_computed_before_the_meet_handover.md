## 0. 判準（規格原文）

*   **D119**（2026-10-27 用戶裁定，甲）：值語境——算術運算元、`==`／`!=` 運算元、一元運算，含 `~%Math` 的算術內建——遇到還不是值的運算元（型別 `@int`、區間 `1..`、補 `!0`），答 `_`。與既有的 `_ + 1` ⟹ `_` 同一條規則，與 `#blur` 的值語境吸收（`SPEC_08` §3.2.2）同構。聯集照舊逐支分配；錨點照舊 ⊥ `#arithmetic_on_anchor`（`SPEC_01` §2.6）。
*   **`SPEC_12` §2.1**：任何引擎優化技術嚴禁破壞格論的單調精煉性質。`@int ⊒ 5`，所以 `@int + 1` 必須 `⊒ 6`；⊥ 不是。
*   **Q-103 的不變式**：一檔、兩次演化、兩次提交是同一個程式——同讀數、同根。`SPEC_03` §1：同一字面重複的鍵是合併，與書寫順序無關。
*   **「⊥ 進歷史」不動**（`SPEC_10` §2.3.1、D33、D44、D56）：真矛盾照舊寫入、照舊回報。

## 1. 缺陷

〔量，`v0.106.0` 標籤建置；eval 在空目錄，提交在新宇宙〕

*   **值語境對還不是值的運算元答 ⊥**：`@int + 1`、`@num * 2`、`(1..) - 1`、`(1..9) / 2`、`!0 + 1`、`~%Math./add (@int, 1)`、`~%Math./sqrt (@num)` 皆 ⊥ `#conflict`；`@int == 5` ⊥；`(1..) == 5` `#false`（`5 == 5` `#true`）；`~%Math./add (_, 1)` ⊥，而 `_ + 1` 是 `_`。對照：`(1 | 2) + 1` ⟹ `2 | 3`。
*   **於是一個衍生欄位在交會之前就凍住**：
    *   一檔裡行序決定答案：根上 `n: @int`、`r: n + 1`、`n: 5` 一次演化、一次提交 ⟹ `_.r` 是 ⊥，根 `fba672c8…`；把 `n: 5` 或 `r: n + 1` 放最前 ⟹ `6`，根 `f6dc16ae…`。`n: 1..`、`n * 2`、`~%Math./add (n, 1)`、`(x -> x + 1) n`、兩層衍生 `m: n + 1`、`r: m + 1` 同（v0.80.0 起量過的每一版）。
    *   三條路：`n: @int`、`r: n + 1` 再寫 `n: 5`，三條路都 ⊥（eval 的 `({ n: @int, r: n + 1 } & { n: 5 }).r` 是 `6`）；`h: { k: @int, r: k + 1 }` 再寫 `h: { k: 5 }`、`r: { z: n + 1 }`：一檔與兩次演化 `6`，兩次提交 ⊥。
*   〔讀〕(1) `eval_math_values`：型別在 `value_context_operand` 被判 ⊥，區間與補落到最後一支 `_ => Conflict`；`eval_binary_cmp` 的原子族同；內建各自的 `_ => Conflict`。(2) 演化逐行落地，`r: n + 1` 落地時暫存只有 `n: @int` ⟹ ⊥；`recipe_instead_of_pure_answer` 對 ⊥ 照留（D33／D44），之後不重讀。(3) 提交判純 thunk 為 ⊥ 即存 ⊥（`project_for_commit`）。**(2)(3) 對真矛盾是對的**（⊥ 在精煉下吸收，之後的寫入救不回來）；錯在 (1) 餵給它們一個假的矛盾。

## 3. 射程＝不變式（不是機制）

*   **M1 值語境答 `_`**：每個算術運算子、`==`／`!=`、`~%Math`（與 `complex.`）的算術內建，型別、區間、補在任一邊；內建對 `_` 也答 `_`（r1）。
*   **M2 另一半——值與矛盾照舊**：值的算術、字串、聯集分配、`_ + 1`、`5 == 5`；`"a" + 1`、`{ a: 1 } + 1`、`5 & 7`、交會後才矛盾的（`n & 7`、`n + "a"`）照舊 ⊥；錨點 `#_ + 1` 照舊 `#arithmetic_on_anchor`；`1 / 0` 照舊 `#numerical_error`；部分施用 `~%Math./add (1)` 照舊是態射（r2）。
*   **M3 一個檔與行序無關**：十一個形，每種行序一個讀數、一個根；交會後的真矛盾在每種行序都是 ⊥（r3）。
*   **M4 三條路一個讀數、一個根**：根上、記錄第一層、`^.k`、清單、內建、`==`、補（r4）；**三個寫入五種分組一個根**（r5）。
*   **M5 真矛盾照舊寫入、照舊回報**：`r: 1 + "a"`、`n: 5`／`r: n + "a"` 報 `#conflict at r`，`c: c + 1` 報 `#divergent`，`h: { k: 1 & 2 }` 報 `#conflict at h.k`；型別上的衍生不再是矛盾，提交不報（r6）。
