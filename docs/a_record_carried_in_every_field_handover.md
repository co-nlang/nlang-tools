## 0. 判準

*   **寫入的成本由寫入的大小界定**（Q-116、Q-117 同一個不變式的最後一個機制）。寫一個 N 個欄位的記錄、N 列的表，演化加提交與 N 同階。
*   **D126（用戶 2026-11-02 裁定）**：還沒強制的值（thunk）的身分裡，每個閉包框以該框的 digest 進入，不再把框整個寫出來。區分力與今天相同——同一組值相等、不同的值不等——只是位元組不同。
*   **紀元**：新倉宣告 `encoding=11`；宣告 10 以下的倉照 v0.118.0 的規則（框整個寫出來）寫、照舊驗；`oo migrate` 把它推到 11。讀數一個都不動。

## 1. 缺陷

〔量，`v0.118.0` 標籤建置；空目錄；自製 SIGPROF 取樣器（`q118-prof`）〕

*   **字面記錄的每個欄位都是帶框的 thunk，框是整個記錄**（`seal_defining_scope`，連 `k: 1` 也是）。`REAL_03` §6 的 `0x17` 規定 Thunk 的身分是「表達式、各幀 Combo、ctx、效應」——**框整個寫出來**，所以一個 N 欄記錄的身分是 N 個 N 欄的框，N² 個位元組；sketch（`field_amplitude`）逐欄位再序列化一次。
*   〔量〕`h: { k0: 1, …, k1999: 1 }` 演化 7.65 秒、提交 13.86 秒（1000 欄 1.94／3.46）；2000 欄都讀 `k0`、都讀外層 `a` 的記錄，提交中止（signal 6，4 GB 上限）；1000 欄讀外層 `a` 在 2 GB 上限下提交答「refusing to store a root this engine cannot read back: store n/ parse: #host_resource_denied」——理由寫成讀不回來，其實是讀回檢查的資源。〔取樣，2000 欄〕演化 98.6% 在 `content_hash`（`session_would_be_listed`、`unify_internal` 的比對），其中 48% 是 sketch。
*   **提交另有三個 N²，都是引擎自己的**（框以 `Arc` 共享給 N 個欄位，走訪卻每個欄位處理一次）：`for_cas_storage` 的 `mark_spans_unknown` 與 `materialize_effect_fields` 對共享的框 `Arc::make_mut`——每個欄位深複製一次整個框；讀回暫存的 `own_its_frames` 對每個欄位問一次「這個框讀起來是不是這個記錄」（`reads_as`，把 N 個欄位印出來比）；舊倉讀出時的 `rekey_identity_names` 對每個欄位重寫一次框，框裡欄位的框再重寫——表一大就耗盡記憶體（參考實作第一版讀 800 列的舊倉表就耗盡 3 GB，v0.118.0 不會，因為它不走這條路）。

## 2. 依據；位址

*   **D126**（`STATUS`）。`REAL_03` §6 `0x17` 一列改成「`[幀數] [各幀 digest：該幀 Combo 的身分 digest，32 位元組]`」；`REAL_02` 的 encoding 表加 11。
*   **位址**：**一個紀元**。動的：新倉裡存著還沒強制的欄位的根（欄位讀名字的記錄、讀外層的記錄、巢狀記錄讀外層、記錄的清單、需要輸入的表本體、讀 local 的欄位、讀欄位的箭頭）；`~%Discovery./identify` 對就地寫的記錄（欄位還沒強制）；延後的本體以位址為鍵的集合，衝突訊息的順序跟著位址（`({ @{ @int }: $ + 1 } & { @{ @int }: $ * 2 }) 5` 由「10 vs 6」變「6 vs 10」）；燃料耗盡的 `#blur` 的 CHS 輸入（含帶框的部分值）；古董 `cef5e484` 夾具的重算 digest（e5 保險絲，見該測試的文件註解）。**不動的**：`x: 0` `b74d7758…`、`v: 1 + 1` `df91a8ad…`、`f: (x -> x + 1)` `258a1a08…`、標準根 `c96c2937…`（標準根裡沒有 Thunk）；欄位都是值的記錄（存進倉時已強制）、清單、表的值本體、聯集、區間；`%id`、`~%Engine./save` 的位址；**宣告 10 以下的倉裡的一切**；所有讀數。
*   **驗收方已預先修訂既有測試 50 支**（每處註 `AMENDED 2026-11-02 for Q-118 (D126)`）：37 支釘的根、13 支新倉的宣告與 `migrate` 的說明。其中兩張表（`a_complement_only_booleans_had` g1、`a_hidden_facet_taken_for_a_name` g1）原本新倉與舊倉共用一個期望值，拆成「新倉／舊倉」兩欄——舊倉那欄是 v0.118.0 的值，**必須不動**。**你不得再改它們**；若你的交付讓其中任何一格與預先修訂的值不同，寫進 8.3。

## 3. 射程＝不變式（不是機制）

*   **M1 寫一個記錄的時間與它的欄位數同階**（r1）：N 與 4N（1000／4000）各演化加提交一次，4N 的 30 秒內落地，且少於 N 的 8 倍——欄位是值、都讀一個欄位、都讀外層坐標、欄位是讀外層的記錄、local 欄位、記錄的清單、N 列的表。
*   **M2 框以 digest 進身分**（r2）：新倉宣告 `encoding=11`；七種帶框的根是 D126 的位址（探針釘的值），讀數同 v0.118.0。
*   **M3 舊倉照舊規則**（r3，真 v0.118.0 夾具）：讀數照舊；之後的寫入落在 **v0.118.0 自己寫在那裡的同一顆根**（驗收方以 v0.118.0 二進位在夾具複本上量得；寫完 v0.118.0 仍打得開、讀得到）；宣告不動；`migrate` 推到 11，並說明鎖掉 v0.101.0 到 v0.118.0；之後舊讀數照舊、新寫入照新規則。
*   **M4 舊倉讀得了大表**（r4）：v0.118.0 寫的倉再寫入 800 列的表，提交、讀回照答；讀回時以舊規則驗、把延後本體的鍵改寫成現行的位址，一個框只改寫一次。
*   **另一半——不帶框的不動**（g1）、**一個值一個位址**（g2：同一個帶框的值以一檔、兩檔、兩次提交寫，同一顆根同一個讀數；`=` 照舊）。
*   **上一張卡學到的，逐條過**：規模格比 N 對 4N；計時格依序跑；不終止的格子給行程上限；**一條捷徑必須證明它與原路逐位元組同**（Q-117）——本卡的三個走訪備忘（`mark_spans_unknown`／`materialize_effect_fields`、`own_its_frames`、`rekey_identity_names`）都是「同一個框只處理一次」，結果必須與逐欄位處理逐位元組同；**你怎麼證明，寫在 8.4 Q2**。

## 5. 必答（請在交付報告裡回答，逐題）

*   **Q1 哪幾步**：寫一個 N 欄記錄時，哪幾步的成本與 N² 成正比；你怎麼拿掉的。
*   **Q2 怎麼知道結果相同**：你的走訪備忘（或你的替代做法）與逐欄位處理給出同一組位元組的證據——用什麼比、在哪些輸入上比、比了幾次。

## 7. 探針完整性（沒有 `#[ignore]`：紅就是紅）

*   紅探針 r1、r2、r3 基線必須是紅的；**你可以讓它們變綠，不得改寫它們的宣稱。** `rustfmt` 不得掃探針檔。每個 `oo` 行程 2 GB 位址空間上限，規模格 30 秒、其餘 60 秒即殺；計時格依序跑。
*   〔驗收方校準〕**兩極皆做**：
    基線 v0.118.0（dev `8bc5ff8` 加本探針、夾具與預先修訂）：探針 **2 綠 4 紅**——r1 錯 6／7（「記錄的清單」一格基線也過：每個元素是兩欄的小記錄，框只有兩欄，它是線性的對照）、r2 錯 8／23（宣告 10、七顆舊根）、r3 錯 3／22（`migrate` 不推、宣告 10、migrate 之後的根）、r4 錯 2／4（v0.118.0 提交 800 列的表中止，2 GB）；g1、g2 綠；預先修訂的 50 支在基線上全紅，紅的正是改過的格。
    參考實作（`q118-ref`，相對 dev 引擎五個檔 `bn_serial.rs`、`value.rs`、`storage.rs`、`dispatch.rs`、`oo/src/main.rs`）：探針 **6／6**；全樹 **308 個目標（`Running` 行）、2915 通過、0 失敗**；conformance **213／213**（空目錄前後 0）；交叉編譯 0 error；規模〔`acc/q118`〕：2000／8000 欄演化 0.14／0.44（值）、0.53／1.17（都讀一個）、0.16／0.48（讀外層）、0.71／1.36（巢狀）、0.75／2.74（表）、1.27／2.92（記錄的清單）、1.45／4.36（local）秒，提交 0.51／2.62、1.13／3.37、0.66／2.49、1.41／4.36、1.68／7.04、2.49／9.73、2.51／7.40 秒。

    **變異**（`acc/q118/mut.py`）：十個，**十個都擋下**——框一律寫出 ⟹ r1 r2 r3；框的 digest 不備忘 ⟹ r1；舊倉的根照新規則寫 ⟹ r3；讀時不試舊規則 ⟹ r3 r4；新倉宣告 10 ⟹ r1 r2 r3；共享的框每個欄位標一次 ⟹ r1 r4；`reads_as` 每個欄位問一次 ⟹ r1；改寫鍵名每個欄位重寫一次框 ⟹ r4；備忘替舊規則作答 ⟹ r3 r4；`migrate` 說錯鎖掉的版本 ⟹ r3。
